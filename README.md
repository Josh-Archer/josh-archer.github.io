# josh-archer.github.io

The personal website of Josh Archer, hosted on GitHub Pages. The site serves as a minimal landing page linking to his GitHub profile.

- **Live site:** [https://josh-archer.github.io](https://josh-archer.github.io)
- **GitHub profile:** [https://github.com/Josh-Archer](https://github.com/Josh-Archer)

## Local development

The site is a static `index.html` file. You can view it locally by opening `index.html` in a web browser or by running a local HTTP server:

```bash
python3 -m http.server
```

Then open `http://localhost:8000` in your browser.
